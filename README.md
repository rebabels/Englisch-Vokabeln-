# Vokabeltrainer

Statische Web-App mit 41 Englisch-Deutsch-Vokabeln. Abfragerichtung wählbar, englische Aussprache per Browser-Sprachausgabe, Antwort aufdecken und schwierige Wörter erneut üben.

## Auf GitHub Pages veröffentlichen
1. Neues öffentliches GitHub-Repository erstellen.
2. **Alle vier Dateien** aus diesem Ordner ins Stammverzeichnis des Repositorys hochladen (`index.html`, `style.css`, `app.js`, `vocabulary.json`).
3. Unter **Settings → Pages → Build and deployment**: **Deploy from a branch**, `main`, `/ (root)` wählen und speichern.
4. Die angezeigte GitHub-Pages-Adresse öffnen.

## Vokabeln ändern
`vocabulary.json` im Repository bearbeiten. Jeder Eintrag besteht aus `en` (Englisch) und `de` (Deutsch). Alternativ über **Eigene Vokabeln laden** lokal eine andere JSON-Datei auswählen (nicht dauerhaft gespeichert).

## Hinweis
Die Aussprache nutzt die Sprachsynthese des jeweiligen Browsers. Qualität und Verfügbarkeit englischer Stimmen unterscheiden sich je nach Gerät. Internet ist zum erstmaligen Laden der GitHub-Pages-Seite nötig.
